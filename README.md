# الكلية العسكرية التكنولوجية (TMC)
## منظومة تسجيل حضور ضيوف حفل التخرج وإدارة وتسكين الأتوبيسات
### Military Technological College – Graduation Guest Registration & Bus Management System

---

## ١. نظرة عامة على المنظومة (System Overview)

منظومة إلكترونية متكاملة مصممة خصيصاً لإدارة عمليات تسجيل حضور ضيوف حفل تخرج طلبة **الكلية العسكرية التكنولوجية** وتسكينهم الميداني المؤتمت في **27 حافلة (أتوبيس)** بسعة **36 مقعداً** للضيوف لكل أتوبيس (إجمالي الطاقة الاستيعابية: **972 مدعواً**)، بالإضافة إلى تعيين قادة الأتوبيسات وإصدار الكشوفات الرسمية المعتمدة للطباعة.

تم بناء المنظومة بهوية مؤسسية عسكرية رسمية رصينة باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL) وباستخدام الشعار الرسمي للكلية العسكرية التكنولوجية (`logo.jpg`).

## ٢. المميزات والخصائص المنفذة (Implemented Features)

### أ. واجهة البوابة السريعة لتسجيل الدخول (Fast Gate Check-in)
* **البحث الفوري بآخر ٧ أرقام من الرقم القومي** مع دعم الأرقام العربية (٠-٩) والإنجليزية (0-9).
* معالجة حالات البحث الفردي، والمدعوين المتشابهين في الـ 7 أرقام (Disambiguation List)، وتنبيه عدم وجود المدعو مع إتاحة الإضافة الفورية.
* **زر تسجيل الدخول والتسكين الفوري:** ينفذ عملية تسجيل الحضور والتسكين التلقائي في أقل من ثانية وبنقرة واحدة مع حفظ التوقيت بالسيرفر.
* **حماية كاملة ضد تكرار التسجيل:** يمنع تسجيل الدخول المزدوج لنفس المدعو ويعرض بيانات تسكينه المسبقة وتوقيتها.
* تهيئة آلية للبحث المتتابع السريع لتسهيل دخول مئات الضيوف في وقت قياسي.

### ب. خوارزمية التسكين الآلي لـ 27 أتوبيساً (Concurrency-Safe Bus Allocation)
* تسكين متسلسل حتمي يبدأ من الأتوبيس رقم 1 وحتى الأتوبيس رقم 27.
* الالتزام الصارم بسعة 36 مقعداً لكل أتوبيس (دون احتساب قائد الأتوبيس).
* تنفيذ العملية داخل معاملة آمنة بقاعدة البيانات (`Prisma Interactive Transactions`) مع تفعيل نمط WAL لحماية التسكين ضد تضارب العمليات المتزامنة (`Race Conditions`).
* تنبيه تشغيلي فوري عند اكتمال الطاقة الاستيعابية الكلية (972 مقعداً).

### ج. تسجيل واعتماد قادة الأتوبيسات (Bus Leaders Management)
* تنبيه المشرف فور وصول أي أتوبيس للحد الأقصى (36 مدعواً) لتسجيل قائد الأتوبيس.
* اختيار الرتبة من قائمة الرتب العسكرية المعتمدة للقوات المسلحة (ملازم، ملازم أول، نقيب، رائد، مقدم، عقيد، عميد، لواء).
* قائد الأتوبيس لا يستهلك أياً من مقاعد الضيوف الـ 36؛ ويظهر كفرد رقم 37 في الكشف الرسمي.
* تمييز بصري فوري بين "أتوبيس مكتمل بانتظار القائد" و "أتوبيس مكتمل ومعتمد".

### د. استيراد كشوف الإكسيل والتحقق الذكي (Excel Import Engine)
* دعم سحب وإفلات ملفات `.xlsx` و `.xls`.
* التعرف الآلي على الأعمدة الخمسة المعتمدة:
  1. `الرقم العسكري`
  2. `اسم الطالب`
  3. `اسم المدعو رباعي`
  4. `درجة القرابة`
  5. `الرقم القومي`
* فحص شامل للأرقام القومية المصرية الـ 14 واستخراج المحافظة وتاريخ الميلاد والنوع ومطابقة سنة الميلاد وكود المحافظة.
* كشف التكرار المزدوج (داخل الملف الواحد، وضد قاعدة البيانات).
* معاينة شاملة للسجلات الصالحة والمرفوضة قبل الحفظ الفعلي.
* إمكانية تحميل تقرير إكسيل تفصيلي بالأخطاء لتصحيحها.
* توفير زر تحميل نموذج إكسيل رسمي فارغ معتمد (`Download Official Template`).

### هـ. تصدير وطباعة الكشوف الرسمية (Official Print & Manifest)
* كشف ركاب رسمي بصيغة A4 مصمم للطباعة الفورية بضغطة زر (`window.print()`).
* ترويسة عسكرية رسمية متكاملة تتضمن الشعار الرسمي للكلية، بيانات الأتوبيس، والقائد، وتوقيعات الاعتماد الثلاثية (قائد الأتوبيس، ضابط أمن الحفل، مدير الكلية).
* تصدير الكشوفات الميدانية وسجلات المدعوين إلى صيغة Microsoft Excel (`.xlsx`).

### و. لوحة القيادة والمتابعة اللحظية (Real-Time Dashboard)
* إحصائيات حية مستخرجة مباشرة من قاعدة البيانات:
  * إجمالي المدعوين
  * عدد الحضور الفعلي
  * الذين لم يحضروا بعد
  * نسبة الحضور المئوية
  * عدد الطلبة
  * الأتوبيسات المكتملة
  * الأتوبيسات قيد التسكين
  * المقاعد المتاحة (من 972)
  * المدعوون غير المخصص لهم أتوبيس
  * الأتوبيسات المكتملة بانتظار تعيين القائد

### ز. سجل التتبع والرقابة (Audit Trail) والأمان
* تسجيل كامل لجميع العمليات الحساسة (تسجيل الدخول، تسكين الضيوف، تعيين القادة، التعديل، استيراد البيانات).
* تقييد صلاحيات الوصول بحسب الدور (مسؤول النظام ADMIN، موظف البوابة GATE_OPERATOR، مشرف العمليات SUPERVISOR).
* إخفاء وتشفير أرقام الهوية الحساسة (`298****0101915`) مع زر إظهار مخصص للمستخدمين المصرح لهم.

## ٣. بنية المنظومة التقنية (Technology Stack)

* **الواجهة الأمامية (Frontend):** React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
* **الخطوط الرسمية:** Cairo و IBM Plex Sans Arabic.
* **الواجهة الخلفية (Backend):** Node.js v24, Express, TypeScript, Multer, XLSX.
* **قاعدة البيانات ونظام الربط:** SQLite (بنمط WAL عالي السرعة) عبر Prisma ORM.
* **الأمان:** JSON Web Tokens (JWT) و Bcrypt Password Hashing.
* **الاختبارات الآلية:** Vitest و Supertest.

## ٤. متطلبات التشغيل السريع (Installation & Setup)

### الخطوة الأولى: تثبيت الحزم (مرة واحدة)
```bash
npm run install:all
```
*(أو الدخول إلى مجلد `server` وتنفيذ `npm install` ثم مجلد `client` وتنفيذ `npm install`)*

### الخطوة الثانية: تهيئة قاعدة البيانات والبيانات الأولية
```bash
npm run db:setup
```
يقوم هذا الأمر بـ:
1. توليد عميل Prisma Client.
2. مزامنة هيكل الجداول في قاعدة البيانات (`prisma db push`).
3. تشغيل سكريبت التهيئة (`prisma/seed.ts`) لتسجيل الـ 27 حافلة، والرتب العسكرية، ودرجات القرابة، وحسابات الدخول المعتمدة.

### الخطوة الثالثة: بناء الواجهة الأمامية وتشغيل الخادم
```bash
# بناء التطبيق بالكامل
npm run build

# تشغيل الخادم
npm start
```
المنظومة ستكون متاحة مباشرة على:
👉 **`http://localhost:5001`**

## ٦. طريقة إنشاء مسؤول نظام جديد بشكل آمن (Secure Admin Creation)

يمكن لمسؤول النظام الحالي إنشاء مستخدمين جدد بأي دور عبر واجهة **"الإعدادات وسجل العمليات" -> "حسابات المستخدمين"**.

أو من خلال سطر الأوامر عبر Node.js:
```bash
cd server
npx tsx -e "
import { PrismaClient } from '@prisma/client';
import bcrypt from 'bcryptjs';
const prisma = new PrismaClient();
async function run() {
  const hash = await bcrypt.hash('كلمة_المرور_الجديدة', 10);
  await prisma.user.create({
    data: {
      username: 'اسم_المسؤول',
      passwordHash: hash,
      fullName: 'الاسم الكامل الرسمي',
      role: 'ADMIN',
      militaryNumber: 'M-XXXX'
    }
  });
  console.log('تم إنشاء المسؤول بنجاح');
}
run();
"
```

## ٨. التشغيل في بيئة الإنتاج الميداني (Production Deployment)

* المنظومة مصممة لتعمل كحزمة مستقلة ذاتية الاستضافة (`Self-contained monolith`) حيث يقوم خادم Express بخدمة ملفات الواجهة المبنية والـ API معاً على نفس المنفذ (افتراضياً `5001`).
* يمكن إدارة العملية في الإنتاج باستخدام **PM2**:
```bash
npm install -g pm2
pm2 start server/dist/index.js --name "tmc-event-system"
pm2 save
```
* في حال الرغبة بربطها مع خادم **Nginx Reverse Proxy**:
```nginx
server {
    listen 80;
    server_name graduation.tmc.edu.eg;

    location / {
        proxy_pass http://127.0.0.1:5001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        client_max_body_size 20M;
    }
}
```
